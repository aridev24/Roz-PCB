# Roz-PCB By AriDev24:

This is my first PCB, or you can also say my first ever hardware project that I ever made. In the beginning, I was scared to make it because it was so complex, but after some time It started to get fun. But that does not mean it got easier; it was still complex and gave me a headache. I never thought that I would be able to make a PCB as my first hardware project. 

## Features:

The following is a list of some features below: 

1. Glow-in-the-dark: whenever you take it into the darkness, the LEDs turn on, and its eyes start glowing, but in the light, the LEDs turn off.
2. You can put it in your room as a decoration so at night when you turn off the lights, it will turn on and look beautiful.
3. You can also attach it to your keychain, a great gift for a tech guy.

## Inspiration:

This PCB is highly inspired by a robot named Roz from the movie "The Wild Robot." I took a beautiful scene from the movie where the robot is holding a little duck and converted that into a PCB


## Components:
- 1x CR2032 battery holder
- 2x 5mm LED
- 2x 2N3904 NPN transistor
- 1x Photoresistor (LDR)
- 2x 470Ω resistor
- 1x 4.7kΩ resistor
- 1x 47kΩ resistor
